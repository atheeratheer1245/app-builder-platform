# تطبيق App Builder للأندرويد

هذا مشروع Android أصلي مستقل لـ App Builder، بواجهات Kotlin أصلية تدعم العربية RTL والإنجليزية LTR. لا يستخدم التطبيق WebView ولا يفتح الموقع داخل التطبيق. يحتفظ بالمشاريع محليًا ويتصل بخدمات App Builder الخادمية فقط لإجراءات الحساب والتصدير عند تفعيلها.

## ما يتطلبه بناء APK حقيقي

يتطلب البناء المحلي JDK 17 أو أحدث وAndroid SDK مع منصة API 35 وأدوات البناء المقابلة. بعد تجهيز هذه المتطلبات، شغّل من هذا المجلد:

```bash
./gradlew :app:assembleRelease
```

يُنشئ الأمر ملفًا في `app/build/outputs/apk/release/`. تم التحقق من إنشاء APK إصدار في بيئة التطوير، لكنه موقّع بشهادة debug حاليًا؛ قبل التوزيع العام يجب إضافة مفتاح توقيع إصدار خاص في بيئة البناء أو خدمة بناء سحابية. لا يحتوي هذا المستودع على مفاتيح توقيع أو أسرار.

## البناء السحابي

يتضمن المجلد ملف `codemagic.yaml` وسير عمل `android_release_artifacts` لخدمة Codemagic. ينتج هذا المسار ملفي APK وAAB حقيقيين من مشروع Android الأصلي. قبل النشر العام أو رفع التطبيق إلى Google Play، تُضاف شهادة Android الخاصة بالإصدار في إعدادات الخدمة ويُبدّل سير العمل إلى بناء إصدار موقّع. يبقى إنتاج IPA مقيدًا بإضافة مشروع iOS وشهادات Apple Developer داخل خدمة البناء.

## السلوك التشغيلي

تعمل واجهات القوالب والمشاريع والأمثلة والتصدير محليًا داخل التطبيق الأصلي. لا يفتح التطبيق متصفحًا داخليًا. الاستثناء الوحيد هو الفاتورة المستضافة لمنصة الدفع، عند تفعيل المسار المدفوع، وتُفتح في متصفح الجهاز الخارجي فقط لحماية بيانات البطاقة.

## حالة التحقق الحالية

تم التحقق من بناء APK وتوقيعه التجريبي وفحص المصدر للتأكد من غياب WebView. لم يُجرَ تحقق مرئي على محاكي أو جهاز في هذه البيئة لأنها لا تتضمن أدوات المحاكي أو ADB أو صورة نظام Android. يبقى اختبار التثبيت والتصفح على جهاز فعلي، ثم توقيع الحزمة بمفتاح إصدار خاص، مطلوبين قبل التوزيع العام.
