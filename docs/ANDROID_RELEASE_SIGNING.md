# Android Release Signing

تم إنشاء مفتاح إصدار خاص لتطبيق **App Builder** في 21 أغسطس 2026. ملف المفتاح وكلمات مروره محفوظة خارج المستودع في مساحة أسرار خاصة، ولا تُخزَّن في GitHub أو في ملفات المشروع.

| البند | القيمة |
| --- | --- |
| الخوارزمية | RSA 4096-bit |
| الاسم المستعار | `app-builder-release` |
| الصلاحية | من 21 أغسطس 2026 إلى 6 يناير 2054 |
| بصمة SHA-1 | `E5:1B:A1:19:19:85:57:71:29:D6:C0:E6:4F:26:37:4F:FB:F1:D2:A2` |
| بصمة SHA-256 | `A1:EA:54:73:A7:6B:AD:03:AD:76:89:CD:E1:A7:1A:EC:E9:24:79:FD:B0:F0:16:7A:EF:02:CC:FE:71:CB:F5:13` |

تستخدم عملية Codemagic مجموعة المتغيرات الآمنة `app_builder_android_signing`. تحتوي هذه المجموعة على ملف المفتاح بصيغة Base64 وكلمات مروره والاسم المستعار، وتفكّ العملية الملف مؤقتًا أثناء البناء فقط. يبني المسار السحابي `assembleRelease` و`bundleRelease`، ثم ينشر APK وAAB الموقّعين.

> يجب الاحتفاظ بنسخة احتياطية مستقلة من ملف المفتاح وكلمات مروره. فقدانها يمنع إصدار تحديثات موثوقة للتطبيقات التي تستعمل هذا التوقيع.
