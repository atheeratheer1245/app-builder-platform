# تكامل فيديو Veo من صورة

## المصدر المعتمد

توضح وثائق Google Gemini API أن نموذج `veo-3.1-generate-preview` ينشئ مقاطع قصيرة من صورة إدخال بوصفها إطار البداية، ويعيد عملية طويلة الأمد يجب استطلاعها حتى تكتمل ثم تنزيل الفيديو الناتج. يدعم Veo 3.1 كذلك التوجيه بالصور والنسب العمودية `9:16` أو الأفقية `16:9`.[1]

## عقد App Builder

يبقى مفتاح `GEMINI_API_KEY` خادميًا فقط. يختار العميل صورة مملوكة لمشروعه ويكتب توجيهًا قصيرًا لحركة الموضوع الرئيسي. ينشئ الخادم عملية Veo، ثم يستطلعها ويخزن نتيجة الفيديو في تخزين المشروع. لا يربط الفيديو بمكوّن الحركة نهائيًا قبل أن يراجعه العميل ويقبله.
