# فحص منشئ الألعاب متعدد الصور

أجري فحص عرض لمسار المحرر في بيئة التطوير بعد نشر دعم مجموعات الصور. ظهرت واجهة مساحة العمل للمستخدم المصادق عليه دون خطأ متصفح ظاهر، لكن المشروع ذي المعرّف المستخدم في الفحص بقي في حالة تحقق ولم يعرض محتوى منشئ الألعاب؛ لذلك لم يُسجَّل هذا الفحص كتحقق مرئي لحقول الاختيار المتعدد.

تغطي اختبارات الوحدة إنشاء مكونات حركة مستقلة لكل صورة شخصية أو وحش أو زعيم أو مرحلة، وتبديل روابط الخلفيات المختارة. اجتازت النسخة اختبارات المشروع الكاملة وبناء الإنتاج قبل النشر.
