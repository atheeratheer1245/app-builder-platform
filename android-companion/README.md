# تطبيق App Builder للأندرويد

هذا مشروع Android مرافق يعرض تجربة App Builder المنشورة داخل تطبيق أصلي؛ لذلك تبقى الواجهة، العربية RTL والإنجليزية LTR، القوالب، الأمثلة، الحسابات ومسارات التصدير متطابقة مع الموقع.

## ما يتطلبه بناء APK حقيقي

يتطلب البناء المحلي JDK 17 وAndroid SDK مع منصة API 35 وأدوات البناء المقابلة. بعد تجهيز هذه المتطلبات، شغّل من هذا المجلد:

```bash
gradle :app:assembleRelease
```

يُنشئ الأمر ملفًا في `app/build/outputs/apk/release/`. قبل التوزيع العام يجب إضافة مفتاح توقيع إصدار حقيقي في بيئة البناء أو خدمة بناء سحابية؛ لا يحتوي هذا المستودع على مفاتيح توقيع أو أسرار.

## السلوك التشغيلي

يفتح التطبيق النطاق المنشور لـ App Builder فقط، ويحافظ على الروابط الداخلية داخل التطبيق، بينما يفتح أي رابط خارجي في المتصفح. يتم التعامل مع محتوى الموقع باعتباره المصدر التشغيلي الوحيد، ولذلك لا توجد بيانات واجهة مكررة أو محتوى تجريبي داخل الحزمة.
