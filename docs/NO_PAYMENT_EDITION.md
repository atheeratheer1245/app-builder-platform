# سياسة النسخة غير المدفوعة من موقع App Builder

هذه النسخة هي **موقع ويب فقط** ولا تنشئ منتج تطبيق جوال مستقلًا. تظل المصادقة والقوالب والمشاريع والمحرر والأصول وطلبات التصدير متاحة، لكن لا توجد فواتير أو حاسبة تكلفة أو صفحة فوترة أو تحويل إلى checkout.

| المجال | سلوك النسخة غير المدفوعة |
|---|---|
| طلب التصدير | ينشئ المستخدم طلب APK أو AAB أو IPA مباشرةً بحالة `queued`، ولا ينشئ سجل دفع. |
| واجهة الموقع | لا يظهر رابط للفوترة، ولا توجد صفحة `/billing` أو شاشة عودة دفع أو حالة دفع للمستخدم. |
| واجهات الخادم | لا يسجّل الخادم أي router باسم `payments`، ولا callback عام لـ Paylink أو webhook لـ Tap. |
| بيانات الدفع السابقة | تبقى جداول `payments` و`tapWebhookEvents` كما هي، دون ترحيل حذفي ودون أي مسار تشغيلي يقرأها أو يكتب إليها. |
| طلبات التصدير السابقة | تُحفظ كما هي. وتظهر الطلبات القديمة ذات الحالة `pending_payment` بوصف أنها طلبات تاريخية مؤجلة، من دون إتاحة أي دفع جديد. |

> الاحتفاظ بجداول الدفع التاريخية يمنع فقدان بيانات سابقة أو كسر العلاقات المرجعية. لا ينبغي حذفها إلا بعد تصدير أرشيف معتمد واتخاذ قرار صريح بشأن مدة الاحتفاظ بالبيانات.

## استعادة الدفع مستقبلًا

إعادة تفعيل الدفع ليست تغيير إعداد فقط. يلزم إنشاء تكامل مزود جديد، وإعادة تسجيل المسارات الآمنة، وإجراء مراجعة أمنية، وإضافة اختبارات تحقق من الدفع قبل أن يصبح أي مسار تحصيل متاحًا للمستخدمين.
