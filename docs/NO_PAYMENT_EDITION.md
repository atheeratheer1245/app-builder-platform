# النسخة المجانية بالكامل من App Builder

> **حالة الوثيقة:** سارية. جميع مزايا المنصة، بما فيها طلبات تصدير APK وAAB وIPA، متاحة من دون دفع أو فواتير أو بوابات دفع.

## سلوك التصدير

عند اختيار مشروع وصيغة تصدير، ينشئ الخادم طلب تصدير محميًا ويضعه مباشرة في حالة `queued`. لا تُطلب معلومات بطاقة، ولا يُنشأ رابط سداد، ولا يوجد callback لمزود دفع.

| المجال | السلوك المعتمد |
|---|---|
| طلب التصدير | طلب محمي يُدرج مباشرة في قائمة البناء |
| التكلفة | مجانية بالكامل؛ قيم السعر المخزنة للطلبات الجديدة تساوي صفرًا |
| حالة التصدير | `queued` ثم `building` أو `ready` عند ربط خدمة البناء السحابية لاحقًا |
| إنشاء الملفات | يتطلب ربط خدمة البناء السحابية؛ ويتطلب IPA حساب Apple Developer وشهادات التوقيع الخاصة بالمالك |
| البيانات التاريخية | تبقى جداول وسجلات الفوترة السابقة في قاعدة البيانات للقراءة التاريخية فقط، من دون مسارات تطبيقية لإنشائها أو تعديلها |

لا تغير هذه السياسة محتوى القوالب نفسها، مثل صفحة الدفع داخل قالب متجر إلكتروني، لأنها تمثل بنية **تطبيق العميل النهائي** الذي قد يختار مالكه لاحقًا دمج وسائل الدفع فيه.
